## 39 — Rationalist, Pandyan → item 48 `பகுத்தறிவுப் பாண்டியனார்!`

**Result: MATCH CONFIRMED / two strong BU errors plus repeated source-wordplay loss.**

The identity is certain: the same Soundarapandian reminiscence, Pattiveeranpatti hospitality, P. T. Rajan contrast, Self-Respect movement history, Cheranmahadevi bridge, women's property-rights resolution and anti-caste close are present throughout.

High-value differences:

1. **Title/register:** BU **Rationalist, Pandyan** drops the honorific force of `பாண்டியனார்` and the canonical terminal `!`. Repository **Rationalist Pandianar!** is more source-facing.
2. **Ayyappan / Poyyappa wordplay:** source `அய்யப்பனை மீண்டும் படைத்திட்ட பி.டி.ராஜனும் / "பொய்யப்பா கடவுள்" எனும் சவுந்தரபாண்டியனும்` deliberately sets Ayyappan against `Poyyappa kadavul`. BU flattens this into a religious P. T. Rajan versus a non-believing Soundarapandian; repository preserves `Poyyappa kadavul` and the sound-play.
3. **Place normalization:** BU modernizes source-position `ஆரூர்` to **Tiruvarur**. Repository retains **Arur**, following the source form.
4. **Strong semantic error:** BU calls `பவள விழா மாநாடு` a **Platinum Jubilee Conference**. `பவள` is **coral**; repository **coral-jubilee conference** is source-supported.
5. **Strong number/metadata error:** BU gives the Chengleput/Self-Respect conference year as **1928**. The FINAL-CLEARED Tamil explicitly prints `ஆயிரத்துத் தொளாயிரத்து இருபத்தி ஒன்பதாம் ஆண்டில்` — **1929**. Repository follows 1929.
6. Source `அரிநாம மந்திரம்` / `மகாமகங்கள்` register is generalized in BU into a generic sacred-name/God formulation; repository retains the Hari-name / Mahamagam wording rather than replacing it with outside normalization.
7. BU carries a bottom date `1993`. It is retained only as secondary-witness metadata here; it does not by itself alter source-controlled repository metadata.

**Classification:** title/register smoothing + wordplay loss + one strong semantic mistranslation (`பவள` → Platinum) + one secondary year error (1929 → 1928).

## 40 — No Day there is That May be his Birthday Called → item 46 `அவன் பிறந்தநாள் என ஒன்றில்லை!`

**Result: MATCH CONFIRMED / one strong lexical error and one severe polarity error in BU.**

The payload is unmistakably the same Anna birthday-paradox poem: golden-age praise, hissing snakes, the heart that subdues them, daily remembrance, tortoise-like restraint, fire when Tamils are harmed, brooding-hen protection, movement training, coral lips / pearl words, diamond eyes and the close that every day nectar-Tamil is born is Anna's birthday.

High-value differences:

1. **Title:** BU's syntactically awkward **No Day there is That May be his Birthday Called** preserves the basic paradox, while repository **There Is No One Day Called His Birthday!** follows the canonical direct title `அவன் பிறந்தநாள் என ஒன்றில்லை!`. The contents variant `ஏன்` remains separately recorded in repository metadata.
2. **Strong lexical error:** source `இனிக்கின்ற வெல்லம்` means sweet **jaggery**. BU renders it as **sweet sugar cane**. Repository **sweet jaggery** is source-controlled.
3. **Image loss:** source `இதய மகுடியாய்` invokes the `மகுடி`, the snake-charmer's flute. BU turns this into the “melody” of the enduring heart, retaining only a generalized musical idea. Repository makes the snake-charmer's-flute image explicit.
4. **Severe polarity/semantic error:** source `நாமம் தொலையா அர்ச்சனைகள் / நாளும் நடக்கும் அண்ணனுக்கு!` is repeated/daily **archanai** — ritual praise/offering — for Anna whose name does not fade. BU renders this as **“Everlasting censure.”** That reverses the source's sense. Repository retains the *archanai* ritual metaphor and is source-correct.
5. **Source-visible syntax:** BU smooths `அடைகாக்கும் கோழி போல / அவனைத்தான் நம்மையெல்லாம்-` into a complete sentence about caring for all of us. Repository deliberately preserves the difficult broken rhetorical syntax because the controlling Tamil itself is source-visible in that form.
6. **Closing expansion:** BU speaks of the “renaissance” of Tamil; source simply says `அமுதத் தமிழ் பிறக்கின்ற / அனைத்து நாளும்` — every day nectar-Tamil is born. Repository stays closer to that source wording.
7. BU carries bottom date **15-09-1994**. It remains secondary-only metadata unless independently supported by the controlling source layer.

**Classification:** title smoothing + lexical/image loss + strong lexical mistranslation (`வெல்லம்` → sugar cane) + severe polarity reversal (`அர்ச்சனைகள்` → censure).
