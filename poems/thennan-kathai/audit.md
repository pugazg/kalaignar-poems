## What the scan-146 failure changes

The latest failure proves that **high resolution plus a second pass is not sufficient** if the reader is still recognizing whole words first. The dominant failure pattern is now specifically:

1. loss or substitution of suffixes such as `-ளை`, `-ை`, `-ஆம்`, `-னால்`, `-ஆள்`, `-னான்`;
2. replacement of unfamiliar printed forms by familiar words;
3. acceptance of semantically plausible readings without accounting for every glyph;
4. repeated confirmation of an already typed candidate;
5. overconfidence in enlarged/resampled crops.

## Final-audit safeguards now mandatory

For the final 145–152 audit:

- read each **complete source line** before consulting the repository line;
- account explicitly for every character and every word-final suffix;
- separately check `-ளை/-ை/-ஆம்/-னால்/-ஆள்/-ன்/-னான்` and similar compact endings;
- use enlarged crops only after establishing whole-line context;
- never use semantic plausibility as evidence for a glyph;
- preserve punctuation, spacing, dashes, separators, and line breaks exactly as printed;
- recheck every stamp/library-mark overlap from source pixels;
- if a page yields a comparable cluster of corrections, supersede its earlier PASS rather than treating the errors as isolated patches.
