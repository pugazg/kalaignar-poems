# Scan 72 — section 8

## Poem text

```text
2. “சீர் சான்ற விழுச் சிறப்பின்,
சிறுகண் யானைப் பெறலருந் தித்தன்
செல்லா நல்லிசை உறந்தை....”

(புறநானூறு : பாடல் : 395
பாடியவர் : நக்கீரர்)

3. “அரிபெய் சிலம்பின் ஆம்பலந் தொடலை,
அரம்போழ் அவ்வளைப் பொலிந்த முன்கை,
இழையணி பணைத்தோள், ஐயை தந்தை,
மழைவளம் தரூஉம் மாவண் தித்தன்...”

(அகநானூறு : பாடல் : 6
பாடியவர் : பரணர்)

4. “மாவண் தித்தன் வெண்ணெல் வேலி
உறந்தை அன்ன உரைசால் நன்கலம்
கொடுப்பவும் கொள்ளா நெடுந்தகையவனே....”

(புறநானூறு : பாடல் : 352
பாடியவர் : பரணர்)

5. சிற்றில் நற்றாண்பற்றி, நின்மகன்
யாண்டுளனோ? என வினவுதி; என்மகன்
யாண்டு உளன் ஆயினும் அறியேன்; ஒரும்
புலி சேர்ந்து போகிய கல் அளை போல,
ஈன்ற வயிறோ இதுவே;
தோன்றுவன் மாதோ, போர்க்களத்தானே!”

(புறநானூறு : பாடல் : 86
பாடியவர் : காவற்பெண்டு)
```
