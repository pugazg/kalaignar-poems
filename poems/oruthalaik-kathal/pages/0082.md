# Scan 82 — section 09

## Poem text

```text
கனையிருஞ் சுருணைக் கனிகாழ் நெடுவேல்
விழவு அயர்ந்தன்ன கொழும்பில் தின்றி
எழா அப் பாணன்...’’

(அகநானூறு : பாடல் : 113
பாடியவர் : கல்லாடனார்)

2. ‘‘குல்லைக் கண்ணி வடுகர் முனையது
பல்வேற் கட்டி நன்னாட்டு உம்பர்...’’

(குறுந்தொகை : பாடல் : 11
பாடியவர் : மாழுவனார்)

3. ‘‘நாகிள வேங்கையின்
கதிர்த்து ஒளி திகழும் நுண்பல் சுணங்கின்
மாக்கண் மலர்ந்த முலையள்...’’

(புறநானூறு : பாடல் : 352
பாடியவர் : பரணர்)

பொருள் விளக்கம் :
இகந்தனவாயினும் = எல்லைகடந்த தூரமாயினும்.
பகைவர் ஓம்பினர் உறையும் கூழ்கெழு குறும்பு = பகைகளைப்
பாதுகாத்து பகைவர் உறையும் உணவு மிகுதியான அரண்!
குவை இமில் விடைய வேற்று ஆ ஒய்யும் = திரண்ட திமில்
கொண்ட காளைகளுடன் கூடிய பகைவர்களின் பசுக்களைக்
கவர்ந்திடும்! சுருணை = பூண். கனிகாழ் = நெய்கனிந்த வேலின்
தண்டு. எழா அப் பாணன் = புறங்கொடாத பாணன்.
நாகிள வேங்கை = கொத்துக் கொத்தாய்ப் பூத்துள்ள இளவேங்கை
மரம். நுண்பல் சுணங்கு = நுண்ணிய பலவாகிய பூந்தாது.
```
