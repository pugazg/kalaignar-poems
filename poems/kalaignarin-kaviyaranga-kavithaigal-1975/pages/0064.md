# Scan 64 — NEW ITEM 02 continuation

## Clearly legible printed text

```text
‘வன்மை’ என்னும் தலைப்பினிலே எண்ணக் கவி
யொருவர் பாடிடுவார்—
உண்மையொன்று சொல்கின்றேன்—
அவர் இரு பெயரில் ஒரு புலவர், முத்துச் சம்பந்தம்—

அன்னை தமிழின் ‘வலிமை’ எனும் தலைப்பினிலே கவிஞர்
அய்யாக்கண்ணு பாடிடுவார்!

அடுத்து—இறைமை!
பாடுபவர்—சிங்கார வடிவேலன்!
சிக்கவிலே வாடும் சிங்கார வேலா—எனப்பாட்டு
கேட்டிருப்பீர்—
தமிழில் இறைமை
எனும்
தலைப்புச்
சிக்கலிலே—இவர் சிறப்புக் கண்டிடுவோம்

அடுத்து ‘புதுமை’
கொடியரசன் பாரிவள்ளல்...கோட்டைக்
கொடியரசன்—முல்லைக்
கொடியரசன்—அவன்
முடியரசன்
குடியரசு தழைக்கின்ற இக்காலம் இங்கோர்
முடியரசன் இருக்கின்றார்......
இவர் கவி முடியரசர்......
விரைவில்
முடியரசு!

பின்னுரை
முன்னுரையில் நான் சொன்ன கருத்தெல்லாம்—மீண்டும்
முடிவுரையில் சொன்னதாய் கொண்டிடுக!
தமிழின் ‘தொன்மை’ தனைத் தரணிக்கு உணர்த்த
திடுவோம்—
```

## Phase 1 notes

The thematic hand-offs `வன்மை / வலிமை / இறைமை / புதுமை`, the named poets, and the `முடியரசன் / முடியரசர்` word-play are visibly supported by the enlarged scan. Minor spacing/punctuation details remain for Phase 2, so this page stays `needs-review`.
