# Scan 33 / printed page 32 — கவிதை தொடர்ச்சி

## Poem text

```text
பண்ணையார் படுத்துறங்கிக் கொண்டிருக்கிறார் - கட்டிலறையில்!
பாடுபடும் பாமரர்கள் நாமேதான் பயணம் போகிறோம் கல்லறைக்கு!

கற்கால மனிதர்களாயிருந்து
கால மாறுதலால்

படிப்படியாய் பண்பட்டு வருகின்றோம்.
பகுத்தறிவும் பெற்றோம் என்பதற்கு

அடையாளமாய் அனைவரும்
ஒன்று சேர்வோம் ; முதலில்

ஏற்றத் தாழ்வை நமக்குள்ளேயிருந்து
எடுத்தெறிவோம் குப்பைத் தொட்டியிலே! அதன் பின்னர்

எல்லாவற்றையும் தலைகீழாய் மாற்றுதற்கு
ஏற்றிடுவோம் புரட்சிக் கொடி! கிளம்பிடு கிளர்ச்சி நடத்த!”

மளமளவென மடை திறந்தாற் போல
மங்கையவள் பேசக் கண்டு -

காயம் பட்டோர் படாதோர் எல்லாம்
வாயைப் பிளந்து கொண்டு, வந்து நின்று ;

அடடே அதிசயமாயிருக்கிறதே -
அழகாகப் பேசுகிறாயே -

அதெப்படி முடிகிறதுன்னால் என்று
அத்தனைபேரும் கேட்க ;
அவள் பதில் சொன்னாள் -

“நான் எனக்காக மட்டும் பேசவில்லை -
எல்லோருக்கும் பேசக் கற்றுக் கொடுக்கவே
நான் பேசக் கற்றுக் கொண்டேன்” என்றாள்.

அதுவரையில் இருள் மறைவில்
அசையாமல் படுத்திருந்த

விழுப்புண் நெஞ்சினிலே பெற்ற வீரனொருவன்
விழித்துக் கொண்டு கேட்டான் ; “என்னைத் தெரிகிறதா மங்கை ?”
```
