# Scan 117 — பெண்ணியத்தின் திண்மை கூறும் குண்டலகேசி!

## Poem text

```text
வணிகப் பெருவேந்தன் கோவலன் ; அவன் காதல் துணைவி
வாய்மை நிறை நடனவல்லி மாதவி ; வாழ்வின் திருவிளக்கென

வாய்த்ததிரு கண்ணகியாம் பெண்ணரசு ; இம்மூவரின்
வழித் தோன்றலாய் வந்துதித்த, வற்றாப் புகழ்

மொழிக்குல மங்கை நல்லாள் ; மன்பதையில் எவர்
பழிப்புக்கும் இடம் தாராத பற்றற்ற துறவி மணிமேகலை -

இவர்களை இணைத்து ஒலிக்கும் சிலம்பும் மேகலையும்,
இணையென ஒளிரும் சீவக சிந்தாமணியும்,

அருந்தமிழ் இலக்கியப் பனுவல் வளையாபதியும்,
ஆணாதிக்கம் வீழ்த்திய ஆரணங்கு பற்றிய குண்டலகேசியும்,

சமணம், பெளத்தம், சைவம், வைணவமென்று - பெருஞ்
சமர்கள் விளைந்த நிலையில் சங்கம் கண்ட புலவர்களும்

சகல கலை புணர் சான்றோர் ஆன்றோர்களும்
சமத்துவம் போற்றிடக் காலம் தேவைப்பட்டதெனினும்

அதற்குள் ஐம்பெருங்காப்பியங்களில் இரண்டை
அந்தோ ; தமிழ் நிலம் இழந்தது விந்தையே!

‘வளையாபதி’ வளைந்தது எங்ஙனம் ?
‘குண்டலகேசி’யின் வடிவு குலைந்தது எவ்விதம் ?

காலமெனும் கரையான தின்றதோ ; தமிழரின்
கவனக் குறைவுதான் காரணமாய் நின்றதோ ?

அறுபது ஆண்டுகளுக்கு மேலிருக்கும் ;
அடியேன் அயராது தேடித் திரிந்து -
```
