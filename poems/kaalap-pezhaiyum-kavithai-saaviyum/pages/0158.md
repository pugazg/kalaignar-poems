# Scan 158 / printed page 157 — கவிதை தொடர்ச்சி

## Poem text

```text
வழங்கியுள்ள சிறப்புரைகளுடனே
வரைந்துள்ள முனைவர் மா. இராசமாணிக்கனாரின்

சோழ வரலாறு படித்திடும் வாய்ப்பு பெற்றேன்.
ஆதிகாலச் சோழ மன்னர்கள் ஆண்டிருந்த காலம்

தொல்காப்பியர் காலத்துக்குத் தொடர்புடைய
கி.மு. ஆயிரம் ஆண்டுகளுக்கு முற்பட்டவை என்பார்.

முதல் வரிசையினராக கி.மு. மூன்றாம் நூற்றாண்டுக்கு
முற்பட்ட சோழர்கள் சிபி, முசுகுந்தன், கந்தன், செம்பியனும்

கி.மு. மூன்றாம் நூற்றாண்டில் “செருப்பாழி எறிந்த
இளஞ்சேட் சென்னி” என்பானும் ஆண்டனராம்!

கி.மு. இரண்டாம் நூற்றாண்டை
மனுநீதிச் சோழனுக்கும், முதல் கரிகாலனுக்கும்

ஒதுக்கியதை ஒப்புக் கொண்டு ;
முதல் நூற்றாண்டுச் சோழன் இரண்டாம் கரிகாலன் என்றும் ;

மூன்றாம் நூற்றாண்டுச் சோழன் முடியுடை வேந்தன் ;
செருப்பாழி எறிந்த இளஞ்சேட் சென்னி என்றும்,

அவனைச் சேர்த்திணைத்து வரும் கி.பி. 1 முதல் கி.பி. 150 வரை
நலங்கிள்ளி, நெடுங்கிள்ளி போன்ற சோழர்க்கு

உரியவை என்றும் அவர் உரைத்திடுவது கண்டு ;
ஓர் அய்யப்பாடு மட்டும் எனக்கெழுந்ததுண்டு!

அஃதென்ன அய்யப்பாடு என்றீரேல் ;
அப்படியொன்றும் பெரிதில்லை ; ஆனால்

அடியேனுக்கு வந்த நினைப்பு ; அடுத்து யாருக்கும்
வரக் கூடாதென்பதற்காக அதனை விளக்குகின்றேன்.

அடைமொழிகளுடன் அனைத்து மன்னர்களும் பெருமை பொங்க
அழைக்கப்படுகிறார்கள் என்கிற போது ;
```
