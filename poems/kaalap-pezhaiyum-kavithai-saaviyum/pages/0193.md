# Scan 193 / printed page 192 — கவிதை தொடர்ச்சி

## Poem text

```text
பல்லவர் தலைநகராம் காஞ்சி தானா என்பதிலே அய்யம் கூட
பல ஆய்வாளர் எழுப்பியதுண்டு ; அதற்குச் சான்றாக

ஆந்திரப் பகுதியில் உள்ள பெத்த காஞ்சி என்பதையே
பல்லவத் தலைநகரமான காஞ்சி என்றும் பெரிதாக
அறிவிக்கின்றார்!

‘யுவான் சுவாங்’ எனும் சீன யாத்திரிகர் கூட அந்தக் காஞ்சியைத்
தான்
உரைத்திருக்கக் கூடுமென யூகித்துச் சொல்லுகின்றார் ;
உண்மை அறிவோம்!

சீன யாத்திரிகரின் சிறப்புக் குறிப்பில் நம்
சிந்தைக்குத் தேன் துளியாகச் செய்தி ஒன்றும் உளது ;

“திராவிட நாட்டில் பல தான்களை அசோகன் நாட்டினான் ;
அவைகளில் சில தான்கள் பழுதடைந்து நிற்கின்றன”

எப்போதெல்லாம், எத்தகைய அறிஞர்களால் எல்லாம்
‘திராவிட’ எனும் பெயர் உச்சரிக்கப்பட்டுள்ளது என்பதை எண்ணி ;

இதயம் விம்முகிறது -
இன்பம் பொங்குகிறது!

சாளுக்கிய புலிகேசி என்பான் சமருக்கு வந்தான்
மகேந்திர வர்மனைப் போரில் மண்டியிடச் செய்வதற்காக ;

பொங்கும் எரிமலையாய்ப் போரில் குதித்தனர் ;
இருபெரும் படையினரும் -

அப்போதொரு பொய்யைக் கல்வெட்டில் செதுக்கினார் ;
புலிகேசி மன்னன் ; புள்ளலூர்ப் போரிலே மகேந்திரன் ஓடி ஒளிந்து
விட்டானென்று!

அதை மறுத்தறிவித்த மாமன்னன் நரசிம்மன்
மாமல்லனும் ஆனபடியால் ; அந்தப் பெயரால் தானே

மாமல்லபுரமே உருவானது - என்பதை மெய்ப்பிக்கும் வண்ணம் -
வருகிறாயா “நெருக்கு நேர் போருக்கு” என்று ;
```
