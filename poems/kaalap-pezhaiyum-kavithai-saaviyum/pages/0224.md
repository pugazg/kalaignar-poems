# Scan 224 / printed page 223 — கவிதை தொடர்ச்சி

## Poem text

```text
அக்காளின் கணவன் அரசின் மிகப் பெரிய அதிகாரி ;
அவன் குந்தவையிடம் ; என்ன எனக்கேட்டு கண் சிமிட்டுவான்!

அங்கிருந்து சற்று விலகிச் சென்று
குந்தவையும் தேவனும் அந்தரங்கம் பேசுவர் -

உரையாடல் நடைபெறும்போதே மகளிர் குழு ஒன்று
மகிழ்ச்சி பொங்க அங்கே வந்து சேரும் -

மகளிர் குழு என்றால் ; அது தான்
மன்னன் இராசராசனின் மனைவியர் கொண்ட குழு -

உலக மகாதேவி, சோழ மாதேவி, நக்கன் தில்லை அழகி,
பஞ்சவன் மாதேவி, திரைலோக்கிய மாதேவி,

அபிமான வல்லி, இலாட மாதேவி, பிரிதிவி மாதேவி,
மீனவன் மாதேவி, வீர நாராயணி, வானமாதேவி

இவர்களில் வானமாதேவிக்குக் கிடைத்த பேரு ;
இராசேந்திர சோழனின் அன்னை என்பதாகும்.

அவனும் ; சோழ மாதேவி தொடங்கி ;
ஒரு சுற்று பதினொரு பேரிடமும் நலம் விசாரித்து விட்டு ;

பாட்டி செம்பியன் மாதேவி பாதம் தொழுது ;
ஈட்டி போன்ற அவள் கையால் வாங்கிக் கொண்டு......

அவைக்க்களம் நோக்கி ஆலோசனைக்குச் செல்வான்
அன்றாடம் இது அருண்மொழி வர்மனின் அரசப் பணியாகும் -

அதற்கிடையே அவன் குடும்பத்திற்கென ஒதுக்கிடும்
நேரத்தில்தான்
அத்தனை சந்திப்புகள்! அன்பு உரையாடல்கள்! அனைத்தும்
களத்தில்

வீசப்படும் வாள்களின் வேகத்தில் ; வேல்களின் விரைவினைப்
போல்!
பரபரப்பு! சுறுசுறுப்பு! என்றோ ஒருநாள் இயற்கை அளித்தால் ;
இடைவேளை!
```
