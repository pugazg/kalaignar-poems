# Scan 202 / printed page 201 — கவிதை தொடர்ச்சி

## Poem text

```text
நகைச்சுவை நாடகம் எழுதி, நடிக்கச் செய்து
சமண புத்த மதங்களை நையாண்டி புரிந்தபோது அந்த

மதப் பிரச்சார நாடகத்தில் மாதகர் காஞ்சியின்
மகிமையுடை கோபுரங்களில் தவழும் முகில்களை குறிப்பிட்டு ;

“கருமுகில் தவழுமாடக் கச்சி யேகம் பன்றே” எனும்
அருள் வாக்கும் அப்பர் வாக்கும் இணைந்து வருவதாக ;

மயிலை வேங்கடசாமி விளக்குவதை விலக்கி விட இயலாதே?
மற்றவை ஒரு புறம் இருப்பினும் ;

மகேந்திரனின் சிறப்புப் பெயர்களில் ஒன்றான
“சித்திர காரப் புலி” எனும் பட்டம் காஞ்சியில் உள்ள

ஏகாம்பரேசுவரர் கோயில் மண்டபத் தூண் ஒன்றில்,
இடம் பெற்றிருப்பது எவ்வாறு எனும் வினா எழுகிறதே!

பல்லவர்களின் ஆட்சிச் சின்னமும் அவர்கள் போற்றிய
பல்வகைக் கலைச் செல்வமும் - பரவியது

பல திசை எனினும் - காஞ்சியைச் சுற்றிலும் அதன்
பக்கமாகவும் தானே பல சான்றுகளைப்

பார்க்க முடிகிறது என்பதையும் ; அதைப்
பெயர்த்தெடுத்து ஆந்திரத்தில் அமைப்பதென்பது ;

வியர்த்தமான வேலை என்பதையும் வீணாகக்
காஞ்சியின் புகழுக்குக் களங்கம் விளைக்கும் செயல் என்பதையும்

உண்மையான தமிழக வரலாறுகள்
உலகின் கண்களில் படாமல் திரையிடப்பட்டுள்ள நிலையில்

இது மற்றோர் திரையாக ; ஆகாமல் தடுத்திட இந்தப்
பல்லவர் வரலாற்றுப் பகுதியின் விளக்கம் பயன்படுமாக!
```
