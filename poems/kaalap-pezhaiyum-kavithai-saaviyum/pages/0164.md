# Scan 164 / printed page 163 — கவிதை தொடர்ச்சி

## Poem text

```text
இருவகை மணமுறை பழந்தமிழர் மணமுறையாம்
இசைக் கருவி ஒலித்து, இறையை வணங்கி, மலரும் அரிசியும்
கலந்த

மங்கல நீராட்டி - அன்றிரவே மணமக்களை இல்லறப்படுத்திடுதல்.
இஃதோர் மண முறை! இன்னொன்று என்னவெனில் ;

“மணமேடையில் எரி வளர்த்தல் இல்லை, தீ வலம் இல்லை -
தட்சணை பெறப் புரோகிதர் இல்லை, இது முற்றும்

தமிழர்க்கே உரிய திருமணம் என்கிறார்”
சீனிவாச அய்யங்கார்;★ சிலப்பதிகாரத்து மண விழாவில்!

மறைவழி காட்டிட மாமுது பார்ப்பான் வருவதையும் -
வலியுறுத்திக் கவனப்படுத்தாமல், தமிழனின் பழைய

வழக்கத்தை மாத்திரம் சுட்டிக் காட்டி விட்டுத் தம்
வழியில் சென்றுள்ளார் எனும் வாய்மையைப் போற்றலாமல்லவா?

இளங்கோவடிகள் தீட்டியுள்ள
பூம்புகார் இலக்கிய வண்ணனை மட்டுமே

வளங்கொழித்த தமிழகத்தின்
பழம்பெரும் நாகரிகச் சிறப்புக்குச் சான்றென

நவின்றிடுவேன் ; இதன் வாயிலாகத்
தமிழ் நிலத்தின் வளம், தமிழர்களின் உளம் - அவர்கள்

பெற்றிருந்த காதல், வீரம், கடமை உணர்வு,
கற்றிருந்த புவியறிவு, வானறிவு - அடடா ;

இதனைச் சிந்தித்துக் கொண்டே யிருக்கும்போது ;
புதிய பூம்புகார் உருவாக்கிடப் பாடுபட்டு வெற்றி கண்ட நமக்கு ;

அந்தப் பழைய பெருமைகளையல்லவா
எருவாக்கி ; இந்தப் பூஞ்செடியை நட்டுள்ளோம் ; இது

பூந்தோட்டமாகிப் பூத்துக் குலுங்கும் மலர்களை நாம் பறித்து,
தமிழன்னையின்
பொற்பாதங்களில் குவித்து மகிழ்வது எப்போது
```
