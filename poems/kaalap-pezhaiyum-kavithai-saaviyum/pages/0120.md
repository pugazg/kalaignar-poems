# Scan 120 — ஈராயிரம் ஆண்டின் முன்னே இந்தத் தமிழ் நிலம்!

## Poem text

```text
சற்றொப்ப இரண்டாயிரம் ஆண்டுக்கு முந்தைய
சரித்திரத்தைத் திரும்பிப் பார்த்தால்

சாவிளக்கு கொளுத்தியது போல சமுத்திரத்தில்
சகல நாட்டுக் கப்பல்களும் வரிசையாக நிற்கின்ற

காட்சி தெரிகிறது, கண்ணிரண்டும் ஒளிர்கிறது -
கலை, நாகரிகம், பண்பாடு இவற்றில் வெல்லலாம் ;

காதும் குளிர்கின்ற தமிழகத் தகவல்களையும் தருகின்றேன்.
கடல் வாணிபம், கடல் கடந்த வெளிநாட்டுறவு, கலை இலக்கியம்,

களம் பல கண்டு வாகை சூடுகின்ற ஆட்சியும் மாட்சியும்,
கனிக் குலையாகக் குவிந்துவரை நானும் உம்மோடு
ரசிக்கின்றேன்!

கண்ணகியின் கற்பும் மாதவியின் மாண்பும் கவிஞர் பெருமான்
காரிக் கண்ணர் வாயிலாக பாண்டிய சோழ மன்னரிடை வளர்ந்த

பற்றும், பாசமும், நட்பும், நாட்டுறவும்
முற்றும் அறிந்து மகிழ்ந்துள்ளோம்.

காவல் அரண் - கட்டுப்பாடுத் திறன் - இவையெதிலும்
காவிரிப்பூம்பட்டினத்தில் இல்லை முரண் ;

கலைச்செல்வமெனிலோ கற்பனைக் கெட்டாப் புகழ் மாதவி ; நாம்
மலைத்திடுமளவுக்குப் பூட்டியிருந்த அணிமணிகளின்

பட்டியலைப் பார்த்தாலே மயக்கம் வரும் ; அவற்றில்
சிலவற்றையாவது சிலப்பதிகாரத்தில் காண்போமே!
இதோ ;
```
