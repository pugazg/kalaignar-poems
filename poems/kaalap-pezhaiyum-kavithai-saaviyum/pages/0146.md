# Scan 146 / printed page 145 — கவிதை தொடர்ச்சி

## Poem text

```text
அருளாளர், ஒளியர் என்பார் ஆரம்பத்தில் எதிர்ப்பு காட்டி
அவனாட்சியினை இறுதியில் ஏற்றுப் பணிந்தனராம்.

ஆக்கப் பணிகள் பல புரிந்தான் என்றும்,
அமைதி தவழ நாடை நடத்தினான் என்றும்

வளநாடு தமிழகம் என்று வையம் வாழ்த்திட
உளமகிழ்ந்து கவிஞர்கள் பாடிட ஆட்சி நடத்திப் பின்னர் ;

ஆழ்கடல் தாண்டி அயல்நாடு உறவுகள் கொண்டிட
அடுத்தொரு தலைநகராய் பூம்புகாரை ஆக்கிக் கொண்டான்

அனைத்துலகச் சிறப்புடைய வண்ணம்
அவன் செங்கோல் ; சோழர் ஆற்றலின் அளவு கோலாயிற்று!

அந்த மாமன்னன் புகழ் அனைவரும் பாடுதல் கண்டு
வெந்து நொந்து போன வடநாட்டார் சில மன்னர் ;

வாளாட்டிப் பார்த்ததினால் - வளவன் ;
வாளெடுத்துக் கிளம்பினான் ; பகை வீழ்த்திச் சாய்த்திட!

வணங்கி பேற்றிட வந்து விட்டோம் என்று
வச்சிரம், அவந்தி, மகதம் முதலிய நாடுகளில்

வணங்கா முடியாய் இருந்தோர் அனைவரும் ;
வளைந்து குனிந்து பல பரிசுகள் வழங்கினர்.

மகத நாட்டான், பட்டி மண்டபமும்,
வச்சிர நாட்டான், கொற்றப் பந்தரும்,
அவந்தி நாட்டரசன் தோரண வாயிலும்,
பரிசாக அளித்து அன்பைப் பகிர்ந்து கொண்டனர்.

மணிமுடி மாமன்னன் கரிகாலன்
மதிப்பைக் குலைத்திடத் - தன்

மண்டையில் உதித்த யோசனை யொன்றை,
மந்திரம் போட்டான் “முகரி”யெனும் வட நாட்டான்.

“காவலனே ; கரிகால் மன்னவனே
காவிரிக்குக் கரை உயர்த்திக் கட்ட

இலங்கைக்குப் படையெடுத்து வென்று
ஏராளமான கைதிகளைக் கொண்டு வரலாமே ?” என்றான்.
```
