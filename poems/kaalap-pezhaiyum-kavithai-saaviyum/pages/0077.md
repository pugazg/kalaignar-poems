# Scan 77 / printed page 76 — கவிதை தொடர்ச்சி

## Poem text

```text
வில்லவன் : மன்னவா, தமிழகம் திரும்ப
வேண்டாமா? புறப்பட்டு
முப்பத்திநான்கு திங்கள்
ஆகின்றனவே.....

சேரன் : புறப்படுவோம் – வில்லவா.
அதற்குள் கண்ணகிக்குச் சிலை
நாட்ட இங்கு கல் எடுக்க வேண்டும்
மல்லவா?

வில்லவன் : ஆமாம்....

சேரன் : அந்தக் கல்லைச் சுமப்பதற்குச்
சரியான எருதுகள் கிடைத்துவிட்டன.
கனக – விஜயா, தமிழரின்
வீரத்தின் மீது வீசினாய் ஒரு
சொல் – இப்போது தூக்கு கல்!

தமிழறிஞர்களும், தகுதி மிக்க ஆய்வாளர்களும்,
தன்மானப் புலவர்களும், உண்மை வரலாறு ;
உணர்ந்திடத் துடிக்கும் ஆர்வலர்களுமன்றோ ;
அங்கிங்கெனாதபடி எங்கெங்கும் அலைந்து தேடி ;
மறைக்கப்பட்ட மணிக் குலத்தைத் கொண்டு வந்து
மகுடத்தில் பொருத்த வேண்டியுள்ளது.
```
