# Scan 135 / printed page 134 — கவிதை தொடர்ச்சி

## Poem text

```text
எத்தனை இனத்தினர்
எத்தகை மனத்தினர்

எத்துணை அரசர்கள்
எவ்வகை ஆட்சிகள் -

முடிந்தது ; முடியாதது!
விடிந்தது ; விடியாதது!
விளைந்தது ; விளையாதது!
வளைந்தது ; வளையாதது!

இமயம் முதல்
காவிரி வரையில் அல்ல -

காவிரிக் கரையிலிருந்து
கங்கைக் கரை வரையில்

நீண்டு கிடக்கும் நிலப் பரப்பில்
ஆண்டு முடித்தோர் சரித்திரமும்,

வாழ்ந்து முடித்தோர் வரலாறும் - இனி
வாழ்ந்திடவும் ஆண்டிடவும் ;

வழி காட்டும் வண்ணம்
தொடர்ந்து காலப் பேழை,

கவிதைச் சாவி கொண்டு
திறக்கப்படுவது திண்ணம்!
```
