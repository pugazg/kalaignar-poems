# Scan 139 / printed page 138 — கவிதை தொடர்ச்சி

## Poem text

```text
அதன் பின்னரும் அங்கிருந்த திராவிடப் பண்பாட்டு இனம் ;
அனைத்து இந்தியப் பெரு நிலத்தின் பேரினம் ஆனது!

அப்பேரின மெனும் பெருந்தருவின்
பெருமை சேர் கிளைகளாகத் தமிழ் இனம் போன்ற

தகைமையுறு இனங்கள் பலவும்,
தகுதி மிகு மொழிகள் பலவும் ;

தழைத்துச் செழித்து, தக்காராம் தமிழ்ப் புலவர்களும் - அப்
புலவர்கள் வாழ்த்திய புரவலராம் புவியாண்ட மன்னர்களும் - அந்த

மன்னர்களாண்ட இந்த மண்ணின் வளமும், அந்த வளம் பெருக்கிட
வலிமை பெருக்கி ; வையம் போற்றிட வாழ்வாங்கு வாழ்ந்த

வரிப்புலியனைய வீரர்களும், அவர்கள் வழி வழி வந்த சூரர்களாம்
தமிழ்க் குலத் தீரர்களும், பகை நாடுகளை எப்படிப் பந்தாடினர் -

வெற்றி சிந்து பாடிட எங்ஙனம் வீரம் விளைத்தனர் -
இவற்றுக்கான சான்றுகளை எல்லாம் எங்கிருந்து தேடிக்
கொணர்வது ?

‘அதற்கேற்ற காலம் சங்க காலம் தான்’ என்று ;
ஆன்றோர்கள் கூறிடுவர் ; அறிவேன் யான்!

இந்தக் காலக் கணிப்பிலே கூட கருத்து வேறுபாடுகள் இருப்பினும்
இராகவ அய்யங்காராம் தமிழ் அறிஞர் காட்டிடும் சான்றுக்கேற்ப ;

கி.மு. நான்காம் நூற்றாண்டுதான் தொடக்கக் காலம், எனக்
கொண்டால் ;
கிழக்கிலிருந்து திசைகளை மேற்கு தெற்கு வடக்கு எனத்
துவங்குவது போல் ;

சேர, சோழ, பாண்டியர் என்று மூவேந்தரை வைத்தே
துவங்கியுள்ளோம் ;
தொடர்ந்திடுவோம் இடையில் துவளாமல் அவ்வாறே!
```
