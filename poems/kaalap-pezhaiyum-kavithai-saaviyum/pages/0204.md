# Scan 204 — பட்டயங்கள், பறைசாற்றுகின்றன!

## Poem text

```text
வாதாபி வீழ்ச்சியைத் தொடர்ந்து
வலிமை இழந்த புலிகேசி மன்னனும்

வீழ்ந்திடவே ; அடுத்து அவன் வழித் தோன்றல்
விக்கிரமாதித்தன் வீறு கொண்டெழுந்தான்!

வீழ்த்தி நசக்க வேண்டும் காஞ்சிப் பல்லவரையென்று,
ஆத்திரத்தில் ; சேர, சோழ, பாண்டிய சிற்றரசர்களாம்

எவர் உதவியும் தனக்குத் தேவையில்லை யென்று
எண்ணிலா வீரர் கொண்ட பெரும்படையுடனே

பல்லவச் சீமை மீது சூறாவளியாய்ச் சூழ்ந்தான் - அது கண்டு,
பாண்டியன் அரிகேசரி நெடுமாறன் ; எரிச்சலுற்று

சேரனையும், சோழனையும் ; அவர்கள் சிற்றரசர்கள் எனினும்
சேர்த்தணைத்துக் கொண்டு செருமுனையில் கூட்டாக ;

நெருப்புமிழும் படைகளுடன் அணி வகுத்து,
நெல்வேலிப் போர்க்களத்தில் ;

சாளுக்கிய விக்கிரமாதித்தனை சந்தித்த காரணத்தால்,
சமாளிக்க முடியாமல் பல்லவர் எல்லையைத் திரும்பிப்
பாராமலே அவன் ;

பயந்து, பதுங்கி ; வந்தேன் வந்தேனென்று வாதாபிக்கே
ஓடிவிட்டான் - அதனை
வியந்து சேக்கிழார் தமிழக அணி பெற்ற வெற்றிக்கு வாழ்த்துப்
பாடினார்!
```
