# Scan 119 / printed page 118 — கவிதை தொடர்ச்சி

## Poem text

```text
“சீ! சீ! நீ என்னைக் கள்வன் என இகழ்ந்தாய், அதனால் ;
சிகரத்திலிருந்து தள்ளப் போகிறேன் - சிதறப் போகிறாய்”
என்றான்.

சில நொடிகளிலே உண்மை புரிந்து கொண்ட அந்த
சீதளப் பூ மாலை உள்ளத்தினாள் ;

வஞ்சகத்தை, சூழ்ச்சிதனை வாள் கொண்டல்ல ;
வஞ்சகத்தாலேதான் வீழ்த்த வேண்டுமென -

“ஆருயிரே! அருமருந்தே! என் ஆவியினை நீ
அகற்று முன்னர் ; கொழுநனைத் தொழுதெழ

கொஞ்ச நேரம் கொடு” எனக் கேட்டாள் -
கொடுத்தான் அந்தக் கொள்ளைக்காரன் - குணக்கேடன்!

பற்றுக் கொண்டவள், பக்தி கொண்டவள், பதியின் மீது - எனும்
பாசாங்கு நாடகத்தைத் திறமையுடன் நடித்துக் காட்டி

பாதி சுற்றி முடிந்தவுடன் ; அந்தப்
பாவியின் ஆவி போக்கிடத் திட்டமிட்டு

மறு பாதி சுற்றுக்கு அவன் காத்திருந்த போது ;
மலைப்பாறை உச்சியிலிருந்து தள்ளிவிட, அந்த

மாபாவி மடிந்து போனான் -
மமதை கொண்ட ஆணாதிக்கத்திற்குப்

பெண்ணியத்தின் திண்மை சொன்ன
குண்டலகேசி இலக்கியம் இன்றில்லை எனினும் ;

இலக்கணமாய் எஞ்சி இருக்கின்றாள் ;
இந்தக் குண்டலகேசி - இவள்,

புத்தமதக் கொள்கையினைப் பரப்ப
எத்தனையோ வாதங்களில் வென்று

பின்னர் ;
முற்றுப் பெற்றாள் வாழ்க்கையிலே அன்று!
```
