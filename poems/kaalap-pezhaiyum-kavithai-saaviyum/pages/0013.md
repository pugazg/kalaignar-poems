# Scan 13 / printed page 12 — படிமுறை வளர்ச்சி

## Poem text

```text
வரைந்து காட்டும் வரலாற்றுப் பேரறிஞர் குறிப்புகளை
வரிக்கு வரி ஒப்புக் கொண்டே ஆக வேண்டும்.

அய்ந்து லட்சம் ஆண்டின் முன்னே
அவதரித்த காலமே முதற் கற்காலம்!

அய்ம்பதினாயிரம் ஆண்டுக்கு முன்பே
அழகிய ; குமரி கண்ட நாகரிகம் ;

அதுதான் குமரிக் கண்ட நாகரிகம்!
அரும்பியது அங்கே - எனினும்

ஐயாயிரம் ஆண்டுக்கு முன்பு வரை அது ;
சிரித்துச் செழித்திருந்து சிந்து வெளியில்!

இலெமூரியா கண்டமென
இனிய நம் குமரிக் கண்டத்துக்கு ;

இன்னொரு பெயர் வாய்த்த காரணம் என்னே ?
இரவில் இரை தேடக் கிளம்பும் இலெமூர் குரங்கினம் ;

இக்கண்டத்தில் எங்கும் நிறைந்திருந்த காட்சி கண்டு
இரவில் திரியும் பேய் என்பதற்கு இலத்தின் மொழியில்

‘இலெமூர்’ என்றும் பெயர் இருந்ததாலே
இப்பெயராலே ‘கிளேட்டர்’ என்பவர் கண்டலாய் அழைத்தார்.

ஒருவேளை உருமாறிச் சீறியும் அளவுக்குப்
பெருங்குமரிக் கண்டத்தைப் பேயாட்டம் நடத்திக் குறுக்கி

நிலம் புடை பெயர்த்ததாலே நீலியே இனி உனக்கு
இலெமூரியா எனும் பெயரே ஏகப் பொருத்தமென

இட்டன்றோ வரலாற்றுப் பேராசிரியப் பெருமக்கள் ;
எனவோர் ஐயப்பாடும் எனக்கு உண்டு என்பேன்!
```
