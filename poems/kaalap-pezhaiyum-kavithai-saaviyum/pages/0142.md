# Scan 142 / printed page 141 — கவிதை தொடர்ச்சி

## Poem text

```text
பாண்டிய நெடுஞ்செழியன், பார் புகழும் வெற்றியைப் பெற்று
தூண்டிற் புழுக்களாய்ப் பகையைத் துடிக்க விட்டு

தோல்வியை அவர்தம் தோளில் சுமக்க விட்டுத்
துரத்தி விட்டான்! மீனக் கொடியை வானில் உயர்த்திவிட்டான்.

தமிழ் மானக் கொடியைத்
தன் கையில் பிடித்து விட்டான்.

போர் முனைக்குப் புறப்பட்ட போது அவன் புலிக்குட்டி -
போர்க் களத்தில் பகை ; அவனுக்குப் பூனைக்குட்டி!

இதனை

இடைக்குன்றார் கிழார் எனும் புலவர் ஏறு
எப்படிப் பாடுகிறார் ; எழுச்சியுடன் என்பதுதான் -

இங்கே நாம் காண வேண்டிய காட்சி ;
கண்டு மகிழ வேண்டிய மாட்சி!

“கிண்கிணி களைந்தகால், ஒண்கழல் தொட்டு ;
குடுமி களைந்த நுதல், வேம்பின் ஒண்தளிர்
நெடுங்கொடி உழிஞைப் பவரொடு மிலைந்து ;
குறுந்தொடி கழித்தகை, சாபம் பற்றி
நெடுந்தேர்க் கொடுஞ்சி பொலிய நின்றோன் -
யார் கொல் ?”

(புறம். 77)

அதாவது ;

கிண்கிணி அணிந்து விளையாடும் மழலைக் குழந்தை ;
அதனை அவிழ்த்து விட்டு,

வீரக் கழல் பூட்டிக் கொண்டு -
தலையில் சிறு குடுமியைக் களைந்து விட்டு,

வேம்பு மாலை சூடி ; அத்துடன்
அமர்க்களத்துக்கான ஆரமும் பூண்டு,
```
