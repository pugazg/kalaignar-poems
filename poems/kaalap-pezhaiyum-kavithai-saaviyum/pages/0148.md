# Scan 148 — மாண்பு நிறை தாயும் மாசற்ற மகனும்!

## Poem text

```text
மாண்பு நிறை தாயும்
மாசற்ற மகனும்!

இயற்கையின் எழில் அனைத்தும்
இருளும் ஒளியுமாய் ;

வானும் முகிலுமாய் ;
கதிரும் நிலவுமாய் ;

கடலும் நிலமுமாய் ;
இவ்விதம் இணையா -

இரண்டிரண்டாய்த் தோன்றி ; அவை
இரண்டறக் கலந்து என -

பேருரு எடுக்காமல்
சீருரு எடுத்துச் சிரிப்பது போல ;

அலையாடும் அழகு கொண்டு
அருவியென நீண்ட கூந்தலும்,

மொட்டிரண்டு உடல் முகப்பிலும்
பட்டுப் போல் மேனியும்,

பவளச் செவ்வாயும்,
பற்கள் முத்தாரமும்,

அவள் அழகுக்கு அழகு செய்ய
இன்னும் என்னென்ன அழகுண்டோ ;

அத்தனை அழகுகளும் அணி வகுத்துப்
படைத்த பெண்ணுருவே தான் ;
```
