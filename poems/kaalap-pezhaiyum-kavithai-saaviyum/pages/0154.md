# Scan 154 / printed page 153 — கவிதை தொடர்ச்சி

## Poem text

```text
போர் மூண்ட போது மட்டுமல்ல
பொதுவில் அரசர் குல அண்ணன் தம்பிகளே ;

பொருதுகின்றார் களத்தில் என்றால்,
புலவர் கோவூர் கிழார் அங்கிருப்பார்!

உடன்பிறப்பாம் நலங்கிள்ளியும்,
நெடுங்கிள்ளியும் ஒருவரோடொருவர்,

மோதுவதை முதலில் தடுத்திட்ட பெரும் புலவர் ; அந்த
முத்தமிழ் வித்தகர் தானே!

இளந்தத்தன் எனும் கவிஞனை ;
இனம் புரியாமல் நெடுங்கிள்ளி

ஒற்றன் எனக் கருதி - அவனை
ஒழித்துக் கட்ட அவசர ஆணை பிறப்பித்தபோது ;

நெடுங்கிள்ளி ஆட்சியின் நீதியையும் ;
நெடுங்கிள்ளியையும் தலை சாயாமல் - தற்காலிகமாக

நிலை பெறச் செய்த பெருமை - அரசியல்
கலையும் கற்றுணர்ந்த அறிஞர் கோவூர் கிழாருக்கே உரியதாம்!

★ ★ ★

மலையமான் திருமுடிக் காரியை வென்று - அவன்
மக்கள் செல்வங்களை மதயானை காலிலிட்டுக் கொல்வதற்கு ;

மன்னன் கிள்ளிவளவன் ஆணையிட்ட போது
மின்னலாய் விரைந்து குறுக்கிட்ட கோவூரார் தான்

கன்னலாம் தமிழர்க் கென்றும்
இன்னமும் வரலாற்றில் வாழும் கவிஞரென்றும்

ஏற்றப்படுகின்றார் ; எம் போன்றோரால்!
போற்றப்படுகின்றார் ; என்றென்றும் வாழ்க என்று!

★ ★ ★
```
