# Scan 257 — படையெடுப்பை முன்கூட்டியே அறிவிக்கும் பண்பாடு!

## Poem text

```text
படையெடுப்பை முன்கூட்டியே
அறிவிக்கும் பண்பாடு!

“சுற்றிச் சுற்றி வருகின்றாயே சோழர் வரலாற்றையே ;
பற்றுக் கொண்டோர் நாங்கள் பாண்டியர் வரலாற்றில் ;

முற்றுப் பெற்றவுடன் பல்லவர் சோழர் வரலாறுகள் ;
சற்று விரைவில் வருக பாண்டியர் பக்கம்” என,

வேண்டியவர், வேண்டாதவர் என்றில்லாமல் ; என்
விருப்பத்துக்குரியோர் பலரும் விரும்பி அழைத்தனர் –

பாவேந்தி வருகின்ற பழைய வரலாறுகளில்
பாண்டியரையே முதலில் வைத்து நான் வடித்த கவிதை

1945 ஆம் ஆண்டிலேயே அய்யாவின் ‘குடியரசு’
அலுவலகத்தில் பணியாற்றிய போதே வெளிவந்ததைப்

படித்துப் பார்க்க வேண்டுகிறேன் ; பாசமுள்ள நெஞ்சங்களை!
நொடிக்குள் உணர்வீர் ; என்னுள்ளத்துக் கொந்தளிப்பை!

“காவிரியின் கரையினிலே
        பெண்ணையின் பாய்ச்சலிலே

சரிதமில்லை ; சரிதமில்லை!
        அய்யகோ தமிழ்நாடே ;

ஆரம்பம் கங்கையிலாம்! பாண்டியர்
        ஆண்டதை யார் கண்டார் ?

சேர் செழிப்பைச் செதுக்கியதெவர் ?
சோழர் வளப்பம் சொன்னதும் உண்டோ ?”
```
