# Scan 194 / printed page 193 — கவிதை தொடர்ச்சி

## Poem text

```text
அறைகூவல் விடுத்தவுடன் - ஓடி
மறையும் அறை எங்குளது என்று ;

புலிகேசி ஓடி ஒளிந்துகொண்டான் ; அதில் புகுந்து கொண்டான்!
பல்லவன் நரசிம்மன் விடவில்லை ; அந்தப் புயங்கொள்ளியை!

பரஞ்சோதியாம் தளபதியை பின்தொடரச் செய்து -
வாதாபி யெனும் புலிகேசியின் தலைநகர் வரையில் சென்று ;

அங்கே ;
புலிகேசியின் முதுகு புண்பட்டை உலகிற்கு உணர்த்தி -
அவர்களை
வாகை சூடியதற்கு அடையாளமாக ;

வாதாபி நகரில் இருந்த அழகான யானைச் சிலை ஒன்றையும்
போரில் கிடைத்த பொருளாகத் தமிழகத்துக்கு எடுத்து வந்தான் -

வாதாபி கணபதி வாழ்த்துடன் இசை நிகழ்ச்சி இன்றைக்கும்
தொடங்குவது ;
அன்றைக்குத் தளபதி பரஞ்சோதி எடுத்து வந்த அந்த யானைச்
சின்னம்

தமிழர்க்கு அறிமுகமான பிறகே தான் ; எனவே
தானாக வந்து வரம் தருபவரல்ல பிள்ளையார் - நம்

தளபதியாம் பரஞ்சோதி போரில் வென்று ; வாதாபியிலிருந்து
தமிழகத்திற்கு கொண்டு வரப்பட்டவர் என்பதே வரலாறு!

★     ★     ★

“மன்னவர்க்குத் தண்டுபோய் வடபுலத்து வாதாபித்
தொன்னகரம் துகளாகத் துணைநெடுங்கை வரையுகைத்தும்

பன்மணியும் நிதிக்குவையும் பகட்டினமும் பரித்தொகையும்
இன்னன எண் ணிலகவர்ந்தே இகரைசன்
முன்கொணர்ந்தார்”
(பெரிய புராணம் - சேக்கிழார்)
```
