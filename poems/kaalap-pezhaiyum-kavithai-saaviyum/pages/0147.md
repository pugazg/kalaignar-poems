# Scan 147 / printed page 146 — கவிதை தொடர்ச்சி

## Poem text

```text
படையெடுத்தான் கரிகாலன் - இலங்கை வீரர்
பன்னீராயிரவரைச் சிறை பிடித்து வந்து ;

பாசனத்துக்குப் பயன்படும் வண்ணம் ; காவிரி
பாய்ந்தோடும் வகையில் கரை அமைத்தான் மன்னன்!

சூழ்ச்சி மிகு தன் ஆலோசனையினால் - மேலும்
மாட்சியன்றோ வந்தது கரிகாலனுக்கென்று ; முகரி

அடுத்தொரு சதி நடத்த ஆயத்தமானபோது ;
எடுத்தனன் கரிகாலன் ஈட்டியினை ;

அழுத்தினன் அதன் முனையால் ;
கொழுத்த ‘முகரி’யாம் கொடியவன் நெற்றியிலே!

அதுவரை ‘முகரி’ முகத்திலிருந்த
அவலட்சணமாம் மூன்றாம் கண்ணொன்று ;

முரசமொன்று போல் முனையில் கிழிந்ததுபோல்
முற்றாகக் கிழிந்து புண்ணாகிப் போன கதையை

வற்றாத தமிழ்க் கவிஞர் ஒட்டக் கூத்தரும் -
எக்காள முழக்கமிட்டு ஜெயங்கொண்டாரும் ;

கவிதைகளாக்கித் திருமாவளவன் கரிகாலனைப்
போற்றிப் பாடியுள்ள நேர்த்தி ;

சாகாப் புகழ் பெற்றத் தமிழர்
சரித்திரத்தின் கீர்த்தியாம்!

இலக்கியம், கல்வெட்டு, செப்பேடு
இவற்றையே நாம் வரலாற்றுக்

குறிப்பாகக் கொள்ள வேண்டியதால்
குழப்பம் சற்று விளையத்தான் செய்கிறது ;

இரு கரிகாலர்களில் இவர்
எவராயினும் - வரும் புகழ்

தமிழர்க்குத் தானே என்று கருதி
தணித்துக் கொள்வோம், தாகம்!

துடைத்துக் கொள்வோம் ;
முழுமை வரலாறில்லா சோகம்!
```
