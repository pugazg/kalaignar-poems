# Scan 50 — பழந்தமிழர் பன்னாட்டுத் தொடர்பு!

## Poem text

```text
ஆதாரம் எதுமில்லாமலோ ;
அறிஞர்கள் கருத்தின்
அருந்துணை தவிர்த்தோ ;
அடியேன் எதனையும்
பிடிவாதமாக வலியுறுத்தித்
திமிர்வாதம் நடத்திப் பழக்கமில்லை.

அதிலும் ;
தமிழ் மொழி, தமிழர்கள்
தமிழக வரலாறு எனும்போது
தான்தோன்றித்தனமாகத்
தத்துபித்தென்று
தக்கோர் முன்னிலையில்
தருக்குடன் நடந்திடும்
வழக்கமுமில்லை.

அதனால் தான் ;
தக்க சான்றுகள் திரட்டி
அந்நாள் தமிழர்கள்
அருங்கலம் செலுத்தி
திறன்பல விளைத்து
திரை கடலோடித்
திரவியம் திரட்டிய
தித்திக்கும் சரிதம் ;
தீட்டிட முனைந்துளேன்.

உலக நாகரிக வளர்ச்சிக்கும்
உறவு நாடுகள் தொடர்புக்கும்
உறுதி நல்கும் பெரு முயற்சி
```
