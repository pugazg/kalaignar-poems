# Scan 185 / printed page 184 — கவிதை தொடர்ச்சி

## Poem text

```text
தலை வணங்கி நன்றியினை ; நற்கிள்ளி தெரிவிக்கபோது,
கலைவண்ண மங்கையொருத்தி ஆங்கே - காதல்

அலையாயும் நெஞ்சுடனே தோழியிடம் ; - அன்பால் அவனை
விலை கொள்ள முடியுமோ என்று விழியால் கேட்டாள்!

நிலை கொள்ள முடியாமல் தவித்திட்ட அம்மங்கை ;
மலை முகடு ஏறிபிறங்கப் பெருமூச்செறிந்திட்ட
நற்கண்ணையெனும் நங்கை!
```
