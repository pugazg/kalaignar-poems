# Scan 160 / printed page 159 — கவிதை தொடர்ச்சி

## Poem text

```text
இளஞ்சேட் சென்னி காலத்திலேதான் ; சோழர் படை
களம் காண வேண்டியிருந்தது மோரியரை எதிர்த்து!

சந்திரகுப்தன் வீரத்தையும், சாணக்கியன் சாதுர்யத்தையும்
சாதகப் பின்னணியாய்க் கொண்டு சாய்த்து விடலாம்,

தமிழகத்தையென்று, தமக்குள்ளே கனவு கண்ட மோரியர்கள்,
அதற்குத்
தடையாய் நின்ற மலைகளைக் கூடத் தகர்த்து முன்னேறினர் ;
மோகூரை நோக்கி!

தென்னாற்காடு மாவட்ட ஆத்தூர் கணவாய்க்கு அண்மையில்
அமைந்ததே
திறன்மிகு சோழர் படையின் பாசறை இருந்த மோகூராம்!

‘பாழி’ யென அமைந்த அந்த ஊரை ‘எறிந்து’ வென்றால்
பகைவராம் மோரியர் பணிந்து ஓடுவர் எனக் கண்ட சோழன்,

படையுடன் வந்த எதிரிகள் கூட்டத்தைப்
பள்ளம் போய் விழுகின்ற வெள்ளம் போல்

பாய்ந்து சென்று ; பல முனைகளில் தாக்கிடவே -
பணிந்தனர் மோரியர் ; பதுங்கினர் படையுடன்!

ஒதுங்கினர் மோகூர் பாசறை விட்டு ;
ஓடினர் பிடரியில் பாதம் பட!

இளஞ்சேட் சென்னி ஈட்டிய அந்த வெற்றி கண்டு தான்
எழுச்சி மிகு விருதாக “செருப்பாழி எறிந்த சென்னி” எனும்

சிறப்பு மிகு பட்டத்தை செந்தமிழ்ப் புலவர்கள் சூடி ; அந்தச்
சிங்கத் தமிழனுக்குச் சூட்டி மகிழ்ந்தனர் ; ஆனந்தப் பள்ளுப்பாடி!
```
