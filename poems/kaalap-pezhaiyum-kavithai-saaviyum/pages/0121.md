# Scan 121 / printed page 120 — கவிதை தொடர்ச்சி

## Poem text

```text
நிலவு, அணிமணி பூட்டித் தன்னை அலங்கரித்துக் கொண்டு
நிற்கிறது நிலைக்கண்ணாடி முன்னால் என்று ;

கற்பனை செய்து கொண்டு காணுங்கள் ஒளிந்து கொண்டு!
காலுக்குப் பொருத்தமாகப் பரியகம், சிலம்பு, பாடகம்

அரியகம், சதங்கையெனும் அணிகலன்களுடன்
அழகிய தொடைகளில் இறுக்கமுறக் ‘குறங்கு செறி’யாம்!

முப்பத்திரண்டு விரிசிகையுடன் முத்துக் கோவை ;
முன்னெழிலைக் காட்டி இடையில் ஒளிரும் உடையில் மேகலை

தோளில் தூயமணி சேர் வளையுடன், கண்டிகையாம் ;
தோடு ; மாணிக்கத்தில்! சூடகம், வைரம் பதித்து!

மயிரொழுங்கமைந்த முன் கையில் வளைகள் பல வகை -
வயிர வளையவுடன், சங்கவளை, தங்கவளை, நவமணி வளை

பவள வளையெனப் பலவித வளைகள் அணிந்தவளின்
பொன்னை அனைத்தையும் மிஞ்சும் புன்னகை முகத்தில்!

வாளை மீனின் வாய் பிளந்தன்ன முடக்கு மோதிரம் -
வண்ணத்தில் சிறந்த செந்நிறம் மிளிரும் மாணிக்கக் கணையாழி ;

காந்தள் விரல் கவின் நிரம்ப, கதிரொளி வீசும்
பாந்தமுள்ள வைரங்கள் சூழ் “மரகத்தாள் செறி”

திண்ணியதும் நுண்ணியதுமான சங்கிலிகள்
பூணும் கரமும், பூ வேலை நிறைந்த சவடி, சரப்பணியும் -

முத்தாரக் கழுத்தில் வித்தாரமாய்ப் பின் தொங்கும் கோவை,
கொத்தாகத் திரண்டு திகழும் சந்திரபாணி வைரக் குதம்பை,

இந்திர நீலத்துடன் இடையிடையே காணப்படும் எழிலார் சங்கும்
மந்திரமோ மாயமோ என மாதவியின் அழகுக்கு அழகான

தொய்யகம், புல்லக மெனத் தொடரும் அணிமணிகள்
மெய்யாகத் தமிழக நாகரிகத்தின்

மென்மையை உணர்த்துகின்ற அடையாளச் சின்னங்களன்றோ!
மெல்லிய பூங்காற்றை நுகருகின்ற உணர்வன்றோ; நம் நெஞ்சில்!
```
