# Scan 75 / printed page 74 — காட்சி 3

## Poem text

```text
கக்கும் கண்களோடு அவை
கொய்யப்படும். தசைகள்
கிழித்தெறியப்படலாம்!
ஆனால் சுயமரியாதை
இரத்தத்தின் சூடு தனியாமல்
அவை கிழிக்கப்படும்,
முரசு தட்டுங்கள்! இமயத்தை
முட்டுங்கள்! தமிழன் தோற்ற
தில்லை! தோற்றதில்லை!
புறப்படுங்கள்!”

காட்சி 3

குயிலாலுவம்.

( சேரன் செங்குட்டுவனுக்கும், கனக விஜயருக்கும் நடைபெற்ற
போரில் செங்குட்டுவன் வெற்றி பெறுகிறான்)

சேரன் : வில்லவா! வெற்றி முழங்கும் இந்த
இடத்திற்கு பெயர் என்ன?

வில்லவன் : குயிலாலுவம்.

சேரன் : குயிலாலுவம், குறித்துக் கொள்!
இந்தப் பாறைகள் அனைத்தும்
பைந்தமிழ் வீரம் தீட்டிய ஏடுகள்!
வெற்றி மட்டும் போதாது வில்லவா,
அந்த வீணர்களை விடக் கூடாது.

வில்லவன் : காஷாய உடையிலே ரிஷிகளைப்
போல் எங்கோ ஒடிவிட்டார்களாம்
கனக விஜயர்கள்....

சேரன் : புதுமையல்ல....
அவர்களுக்கு உரியதான ஒரே
பழக்கம் அதுதான்!
(கனக விஜயர்கள் சாமியார்
உடையில் கொண்டு வரப்படுகிறார்கள்)
```
