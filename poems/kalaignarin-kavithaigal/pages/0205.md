# Scan 205 — நேரு கண்ட ஜனநாயகம்

## Printed title / event note

நேரு கண்ட ஜனநாயகம்

14.11.1970 அன்று சென்னையில் ‘நேரு கண்ட
ஜனநாயகம்’ என்ற தலைப்பில்
நடைபெற்ற கவியரங்கில்
கலைஞர் மு.கருணாநிதி அவர்களின்
தலைமைக் கவிதையுரை
★

## Poem / speaker text — verified

```text
தங்கக் குணம் படைத்த நாவலரே
தகைமைசால் அமைச்சர்களே
சங்கத் தமிழ் எடுத்துக் கவி பாட வந்திட்ட புலவர்களே
சான்றோரே
வணக்கம் ஏற்றிடுக!
வங்கக் கடலருகே உறங்குகின்ற நம் அண்ணன்
அடிதொழுது தொடங்குகின்றேன் தலைமையுரை;
புன்னை மரம் நிழல் விரிக்கத் - தமிழ்
அன்னை மடி சுகம் அளிக்க
சென்னை நகர் ஒளி தெளிக்க
முன்னை இருள் விலக்குதற்கு
முயல்கின்ற தமிழ் அரசு
முதுபெரியோன் காந்தியாரின்
மூத்த பிள்ளை நேருவுக்கு
முத்தமிழால் கவி தொடுக்கும்;
```
