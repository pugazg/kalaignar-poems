# Scan 116 — அருமறையில் அறுவர் opening

## Printed heading / context

### அருமறையில் அறுவர்

```text
10.8.68 அன்று தமிழ் வட்டத்தின் சார்பில்
சென்னையில் ‘அருமறையில் அறுவர்’
எனும் தலைப்பில் நடைபெற்ற கவியரங்கில்
கலைஞர் மு. கருணாநிதி
அவர்களின் தலைமைக் கவிதையுரை
```

## Poem text — first-pass

```text
அவை நடுவினிலே வீற்றிருக்கும் ஆன்றோரே,
அறிவாளர் பெரியோரே
அன்புத் தாய்மாரே,
⟦மங்கலான செய்யுள் பகுதி⟧
தமிழ்த் திருமறையும் கவிதையும் வழங்கிருக்கும்
பெருமையைப் புலவர்களே! வணங்குகின்றேன்!
⟦மங்கலான தொடர்ச்சி⟧
```
