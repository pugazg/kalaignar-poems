# Scan 101 — காதலா - வீரமா? opening

## Printed heading / context

### காதலா - வீரமா?

```text
4-8-68 அன்று சேலத்தில் 'தமிழர் வாழ்வில்
சிறந்தது காதலா? வீரமா?' என்ற தலைப்பில்
நடைபெற்ற கவிதைப் பட்டிமன்றம்.
கலைஞர் மு.கருணாநிதி அவர்களின்
தலைமைக் கவிதை முன்னுரை
```

## Poem text

```text
ஏர் வரா வயல் தனிலே எது வரும்?
புல் பூண்டு வரும்.
ஏர் வரின் நெல் வளம் வரும்
வானில்
கார் வரா காலத்தில் எது வரும்?
கடும் பஞ்சம் வரும்
கார் வரின் இன்பக் கனி வரும்
சேர்வரா 'அயன்' மலையில் எது வரும்?
சேர்வராயன் மலையில் எது வரும்? இரும்பு வரும்.
அனைவரும் சேர்வரின் நிலை வரும்
அனைவரும் சேர்வர் இன்நிலை வரும்
நிலை வரும்
தேர் வரும் பலர் இழுத்தால்: அதுபோலத்
தேன் இரும்பு வரும் சேலத்தில். இந்த
```
