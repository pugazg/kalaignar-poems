# Scan 135 / printed page 118 — புதிய பாதை continuation

## Poem / speaker text — first-pass

```text
கொஞ்சப்பா தமிழினிலே எனக் கூறிப்
பஞ்சப்பா போக்குதற்கு
நஞ்சப்பா பாட⟦…⟧

(கவிஞர் நஞ்சப்பா ‘மக்காச் சோளம்’ பற்றிப் பாடி முடிக்கிறார்)

தலைவர் கலைஞர்:

கம்படுத்த வருகிறார் ஒரு கவிஞர்
⟦மங்கலான செய்யுள் பகுதி⟧

(கவிஞர் இராதாகிருஷ்ணன் ‘கம்பு பயிரிடல்’ பற்றிப் பாடி முடிக்கிறார்)

தலைவர் கலைஞர்:

தாமரைக் குளத்தினிலே ராகி விளைகின்ற விந்தை
⟦மங்கலான செய்யுள் பகுதி⟧

(கவிஞர் செல்லப்பாண்டியன் ‘ராகி’ பற்றிப் பாடி முடிக்கிறார்)

தலைவர் கலைஞர்:

மூவேந்தர் எனும் பெயரில்
பாடவேந்தர் பரம்பரையில்
⟦scan 136-ல் தொடர்கிறது⟧
```
